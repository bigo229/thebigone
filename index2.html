How to Install via Kodi File Manager

To add this repository directly inside Kodi, use the following URL source:

https://bigo229.github.io/thebigone/repo/
  1. Open Kodi and go to Settings (the gear icon).
  2. Select File Manager → Add Source.
  3. Double-click <None> and enter the URL exactly as shown above.
  4. Name the source (e.g., .myrepo) and click OK.
  5. Go back to the Kodi home screen and select Add-ons.
  6. Click the Add-on Browser (open box icon) in the top left.
  7. Select Install from zip file (Enable Unknown Sources if prompted).
  8. Select the source you named, then click the .zip file to install.
  9. Once installed, select Install from repository to view available add-ons!
